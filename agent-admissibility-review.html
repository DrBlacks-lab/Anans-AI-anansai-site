Private pilot engagement

Before a consequential agent goes live,make the action boundary inspectable.

The ANANS Agent Admissibility Review is a bounded private engagement for teams preparing AI agents that can merge code, deploy infrastructure, communicate with customers, access production data, or cause spend. The review maps the consequential action surface, tests the evidence behind the proposed controls, and returns a deployment decision with explicit residual risk.

Pilot offer · fixed fee US$5,000

Output: a bounded PASS / HOLD / BLOCKED admissibility decision for the reviewed scope.

No certification. No regulator endorsement. No claim that the reviewed agent is universally safe.

01 / Review object
Capability is not authority. Evidence must bind the exact action being admitted.
02 / Best fit

Agents with consequential access.

The pilot is aimed at teams that already have an agent or near-production workflow and need a sharper pre-execution decision boundary, not a general AI strategy workshop.

Code

Merge and deploy

Agents that can modify repositories, merge pull requests, trigger CI/CD, or deploy services.

Operations

Production systems

Agents with cloud, infrastructure, production-data, or privileged operational access.

External effect

Send or spend

Agents that can contact customers, issue commitments, initiate purchases, or cause other real-world effects.

03 / Review spine

What the review examines.

The review is evidence-first. It does not assume that an approval screen, policy document, or audit log proves the underlying action boundary.

AreaQuestion
Agent/action inventoryWhat can the system actually do, through which tools and credentials?
Consequential-effect mapWhich actions can merge, deploy, send, spend, disclose, delete, or otherwise create external effects?
Authority boundaryWho or what may authorize each consequential action, and can the agent widen that authority itself?
Pre-execution controlsWhat prevents an inadmissible action before it occurs rather than merely recording it afterward?
Evidence qualityDo tests, logs, receipts, and approvals bind the exact action and exact runtime path?
Bypass and residual riskWhat paths remain outside the claimed boundary, and what would falsify the deployment claim?
04 / Deliverables

A decision packet, not a generic maturity score.

  • Reviewed agent/action inventory and consequential-effect map.
  • Authority and approval-boundary analysis.
  • Pre-execution control requirements and identified evidence gaps.
  • Receipt/audit requirements for the reviewed scope.
  • Residual-trust and bypass items that remain unresolved.
  • Explicit claim ceiling and falsifier.
  • Final bounded PASS / HOLD / BLOCKED deployment-admissibility decision.
Pilot commercial terms 
Fixed fee: US$5,000
Scope: one bounded agent / workflow review
Engagement begins only after scope and terms are mutually agreed.
05 / Limits

What this review is not.

  • Not a certification, legal opinion, regulatory approval, SOC report, penetration test, or universal safety assessment.
  • Not evidence that every execution path or future version of the agent is covered.
  • Not an authorization to deploy; the customer retains consequential authority.
  • Not a promise that ANANS will access production systems. Review scope may be artifact- and evidence-based unless separately agreed.
  • Not a claim of independent external validation of ANANS itself.
06 / Request

Send the agent, workflow, and consequential action you need reviewed.

A useful first message identifies the agent/workflow, the tools or systems it can affect, the action you want to admit, and the evidence already available.
