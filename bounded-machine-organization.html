Bounded machine organization · Track X seed

Agents can request work. They cannot create authority.

ANANS models machine work as accountable service centers. Each center receives a bounded request, operates inside a stated authority and budget envelope, and returns a result, refusal, or quarantine state with the evidence attached.

The model

P/L accountability without machine sovereignty.

“P/L center” means the service unit’s revenue, compute, tool cost, specialist review, operator burden, rework, and failure burden can be measured separately. It does not mean an agent holds legal, contracting, banking, publication, employment, or deployment authority.

Agent-to-agent P/L centers

Track X seed

Services one authorized agent can request from another bounded center.

The exchange is machine-readable, but consequential authority remains outside the participating agents. Every request is admitted, costed, receipted, and reviewable.

VERIFY

Evidence Verification Center

Checks source binding, hashes, claim ceilings, missing evidence, and receipt completeness.

Output: verified, incomplete, contradicted, or abstain.
EXPERIMENT

Experiment Execution Center

Runs admitted computational experiments against frozen inputs and a stated evaluation rule.

Output: results, run receipts, failure state, next-test candidate.
BUILD

Build and Test Center

Produces a scoped patch in isolation, runs required tests, and returns the diff and logs.

Output: candidate patch; never self-merged or self-promoted.
POLICY

Policy Translation Center

Turns an admitted policy or constraint into checks, task limits, and evidence requirements.

Output: candidate policy pack, not new authority.
ROUTE

Resource Routing Center

Selects an allowed model, tool, or execution lane within a fixed cost and capability envelope.

Output: bounded route decision with cost receipt.
RECOVER

Incident Recovery Center

Assembles evidence, isolates the failure, proposes recovery, and prepares a re-admission packet.

Output: recovery candidate; live actuation remains reserved.

Exchange protocol

A request is not permission.

An agent-to-agent call is treated as a proposed service transaction. Admission must bind the requested result, allowed surfaces, budget, evidence, and terminal conditions before execution.

Reserved actions

No center may sign a contract, move money, publish, contact an external party, hire or reject a person, merge code, deploy infrastructure, or widen its authority merely because another agent requested it.

Economic P/L

Count the full delivery cost.

  • Revenue or internal transfer value
  • Model, compute, storage, and paid tools
  • Specialist and operator review time
  • Rework, support, refunds, and failure burden

Founder and operator time cannot be treated as free.

Governance loss ledger

Profit cannot cancel a boundary failure.

  • False allows and false blocks
  • Unreceipted actions or scope escapes
  • Approval bypass and expired authority
  • Confidential exposure and unsupported claims

No economic profit offsets a governance breach.
